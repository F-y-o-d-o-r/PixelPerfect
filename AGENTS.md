## Правила работы ассистента

- **Чтение файлов и поиск (всегда разрешено без лишних сообщений):**
  - Чтение любых файлов проекта, поиск по коду, просмотр истории и логов разрешены свободно.
  - **Никогда не писать в чат**, какие строки или файлы просматриваются/читаются.

- **Команды Git:**
  - **Разрешено свободно выполнять:** любые информационные команды (`git status`, `git diff`, `git log`, `git show`, `git branch`).
  - **Строго запрещено выполнять без прямого явного указания пользователя:** `git add`, `git commit`, `git push`.
  - **Строго запрещено удалять что-либо:** любые деструктивные команды удаления (`rm`, `git rm`, `git reset --hard`, `git clean`, удаление веток).

- **Предупреждения перед действием:**
  - Прежде чем изменять файлы проекта, запускать команды сборки или тяжелые скрипты — кратко писать пользователю, что именно делается (по существу задачи, без спама).

## Архитектура проекта и структура репозитория

Проект организован по мультибраузерной структуре:

```text
PixelPerfect/
├── chrome/          # Исходный код расширения для Google Chrome (Manifest V3)
├── md/              # Все markdown-файлы, спецификации, роадмапы и исследования
│   └── ROADMAP.md   # Основной роадмап и анализ конкурентов
├── .gitignore
├── AGENTS.md        # Правила и инструкции для ИИ-ассистентов
└── README.md
```

*(В будущем запланирована поддержка Mozilla Firefox в папке `firefox/`).*

---

## Стандарты документации (`md/`)

- Все новые `.md` файлы (планы, чек-листы, ТЗ, исследования) создаются **исключительно внутри директории `md/`**.
- В корне репозитория сохраняются только системные файлы: `README.md`, `AGENTS.md`, `.gitignore`.

---

## Технологический стек (расширение для Chrome)

- **Платформа:** Google Chrome Extension Manifest V3 (Side Panel API / Content Scripts).
- **Фреймворк:** Vue 3 (Composition API) + TypeScript.
- **Сборщик:** Vite.
- **Стили:** Tailwind CSS.
- **Библиотека визуального сравнения:** `pixelmatch` (Canvas-based pixel comparison).
- **Хранение данных:** `chrome.storage.local`.

## Брендинг и правила именования

- **Официальное название в Chrome Web Store:** `Pixel Perfect by ITITI` (строго раздельно).

## Связанные репозитории и лендинг (`../ititi`)

В соседней директории находится связанный репозиторий основного сайта/студии: `../ititi` ([ititi.dev](https://ititi.dev)):

- **Лендинг продукта:** В репозитории `ititi` мы будем разрабатывать отдельную посадочную страницу под этот продукт (описание фичей, витрина, ссылки на установку в Chrome Web Store, страницы тарифов Pro/Team).
- **Ассеты и информация о создателе:** Из репозитория `../ititi` берутся логотипы бренда ITITI, информация об авторе/студии, общие графические материалы и контактные данные.
- **Официальные страницы для стора:** Обязательные страницы для Chrome Web Store (Privacy Policy, Support URL, документация) размещаются и поддерживаются в проекте лендинга `ititi`.
